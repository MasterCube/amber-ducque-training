# Amber / DuCQUE Training

Training repository for learning AmberTools, molecular dynamics workflows,
trajectory analysis, nucleic-acid simulations, restraints, replicates,
Sherlock HPC workflows, and DuCQUE.

## Contents

- `00_notes/` — general notes and references
- `01_alanine/` — alanine exercises
- `02_tleap/` — tleap and system preparation
- `03_dna/` — DNA simulations
- `04_cpptraj/` — trajectory analysis with cpptraj
- `05_rna/` — RNA simulations
- `06_dna_rna/` — combined DNA/RNA exercises
- `07_restraints/` — restraint methods
- `08_replicates/` — replicate simulations
- `09_sherlock/` — Stanford Sherlock/HPC workflows
- `10_ducque/` — DuCQUE workflows
- `refresher_stage1A/` — tLEaP with fasciculin case
